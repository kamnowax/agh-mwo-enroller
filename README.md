# AGH MWO Enroller

Projekt REST API wykonany w ramach laboratoriów z Programowania Aplikacji Webowych 2.

## Zrealizowane funkcjonalności
- CRUD dla Participants i Meetings
- filtrowanie i sortowanie uczestników
- zarządzanie uczestnikami w spotkaniach
- deployment aplikacji z użyciem Dockera i Render
